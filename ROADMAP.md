# Roadmap

Status labels: implemented, in development, planned. Dates are not promises.

## 0.1 — Reliable MVP
- Simulator → energy → HUD → MCP: implemented
- Claude Code setup, remove, doctor: implemented
- Camera capture and single-hand tap detector: in development
- Calibration onboarding: planned
- Separate background service shared by the HUD and CLI: planned
- Signed macOS package: planned

## 0.2 — Game engine
- Two hands, rhythm/BPM, combo tiers, Overdrive: planned

## 0.3 — Stats
- SQLite aggregates, daily stats, session summary, opt-in Git observation: planned

## 0.4 — Adaptive calibration and a second agent adapter
- Adaptive per-finger thresholds, gesture pause/resume, one more tested client: planned

## Out of scope for now
Linux/Windows, remote gateways, cloud accounts, telemetry.
